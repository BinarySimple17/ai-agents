# BL-009 — Гигиена индексации знаний (Minors ревью S06)

**Источник:** REVIEW-GATE S06 (2026-11-20), Minor M1/M3.
**Приоритет:** P2. **Веха:** V3 «Гибридная память» (BL-007) — вместе с пересборкой корпуса.

## M1 — SoT списка бизнес-таблиц
`BUSINESS_TABLES` дублируется: `knowledge_sources.py`, `test_infra_schema.py`,
SYSTEM_PROMPT cli.py, сиды. Новая бизнес-таблица молча не попадёт в DDL-доки.
**Фикс:** естественный SoT — каталог `agent_data_sources` (ADR-011): индексатор
читает список таблиц из каталога (v1 — все таблицы pg/sql), тест и SYSTEM_PROMPT
сверяются с ним же.

## M3 — устаревшие source_ref / смена эмбеддера
Индексатор только upsert-ит: `source_ref`, удалённый из источников, остаётся в
памяти; после смены эмбеддера строки живут в другом векторном пространстве
(поиск не фильтрует по `model_version`).
**Фикс:** транзакционное удаление устаревших `source_ref` при индексации
(сначала собрать фактические ref'ы источников, затем DELETE недостающих в той же
транзакции с upsert) + при смене эмбеддера — полная пересборка (или фильтр поиска
по `model_version` до пересборки).

## Не в этом беклоге
Гибрид dense+FTS/RRF, шумовой корпус, hit@5, реранкер — BL-007 (V3).
