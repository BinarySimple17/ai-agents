# BL-062 — Явный список колонок не сверяется с каталогом фактических колонок

- **Статус:** открыт
- **Дата:** 2026-11-28
- **Сессия-источник:** S33 (отложено архитектором, ARCH-GATE «Отложено»)
- **Приоритет:** P3

## Что обнаружено

Каталог колонок (S33 R2) сверяется только с '*'-правами; явный список колонок
(`orders: [id, total]`) каталогу не сверяется: несуществующее имя в явном списке
отказывается как «вне прав» (denied → degrade без retry), а не как
hallucination («колонки нет» → retry с подсказкой). Консервативное поведение
до-сессийного мира сохранено сознательно: список — уже сужение гранта, ложное
«несуществует» зацикливало бы retry.

## Почему вне скоупа сессии

Не блокирует приёмку S33 (A5 закрывает '*'— класс, попавший в живые трейсы);
отказ корректен (fail-closed), вопрос — качество диагностики, не безопасности.
