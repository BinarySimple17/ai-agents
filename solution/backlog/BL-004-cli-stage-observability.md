# BL-004 — Консольная наблюдаемость CLI: этапы агента (вызовы модели, тулa, результат ≤5 строк, ретраи, деградация) не видны

- **Статус:** открыт
- **Дата:** 2026-11-19
- **Сессия-источник:** — (директива владельца 2026-11-19: «cli выводил этапы работы агента в консоль… »)
- **Приоритет:** P1

## Что обнаружено

1. **CLI печатает только финальный ответ**: вызовы модели, вызовы тулa `run_sql` с SQL, результат (Observation), ретраи пустых ответов, исчерпание капа ходов, деградация — всё невидимо в консоли; прогон разбирается только по JSONL-трейсу post-factum.
2. **Результат тулa не показывается вовсе** — владелец хочет видеть данные (строки), даже обрезанные до 5: оператор должен понимать, на каких данных модель строит ответ.
3. **События провайдера (`llm.*`) уже идут в JSONL** (порт `Tracer`), но не рендерятся человеку; события самого цикла агента (ходы, tool_call, observation, ретраи) не эмитятся вовсе.

## Почему вне скоупа сессии

Директива пришла вне закрывающих сессий (D-020/D-021 — точечные фиксы провайдера); объём — отдельный адаптер наблюдаемости + события цикла + тесты — оформлен сессией **S21** (solution/sessions/S21_session.md), исполняемой по стандартному конвейеру.
