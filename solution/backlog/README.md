# Backlog — обнаруженное вне скоупа

Каждая запись — отдельный файл `BL-NN-краткое-имя.md` в этой папке. Запись создаёт
сессия, обнаружившая что-то вне своего скоупа (правило 11 канона S00); приёмка сессии
от записи не зависит. Закрытие записи (реализовали / отказались / перенесли) — правкой
`Статус: → закрыт (дата)` в шапке файла; закрытые записи переносятся в [archive/](archive/)
скриптом `make archive` при закрытии сессии. Живые записи — всегда в корне этой папки.

## Реестр

| ID | Название | Статус | Сессия-источник | Приоритет |
|---|---|---|---|---|
| [BL-001](BL-001-guardrails-runtime.md) | Guardrails времени выполнения (I1/I2/rate-limit) не покрыты фичами | открыт | harness (аудит, FIX-005) | P2 |
| [BL-002](BL-002-docs-sync-review-03.md) | Синхронизация канона docs/ с ревью-03 (до S02: ADR-004/005/006/007, prd, диаграммы, RISKS, model-card) | **закрыт 2026-11-18 (S20)** | apply-review-03 (FIX-006, D-015…017) | P1 |

При создании записи — добавить строку в реестр; при закрытии — обновить статус в реестре (файл уедет в archive/, строка остаётся как история).

## Шаблон записи

```markdown
# BL-NN — [Название: что обнаружено, одной фразой]

- **Статус:** открыт <!-- открыт | закрыт (ГГГГ-ММ-ДД: реализовано в feat-0XX / отказано: причина / перенесено: куда) -->
- **Дата:** ГГГГ-ММ-ДД
- **Сессия-источник:** S0N
- **Приоритет:** P1 | P2 | P3

## Что обнаружено

[кратко: факт/проблема/возможность, где наткнулись]

## Почему вне скоупа сессии

[одна строка: не влияет на приёмку текущей сессии]

## Закрытие (заполняется при закрытии)

[что решили и куда: feat-XXX / backlog другого проекта / отказ]
```
