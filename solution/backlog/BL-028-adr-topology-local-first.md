# BL-028 — Нет ADR на топологию N1 и на local-first (D-020)

- **Статус:** открыт
- **Дата:** 2026-11-24
- **Сессия-источник:** S29 (триаж аудита 2026-11-23, E5)
- **Приоритет:** P2
- **Назначение:** V6 (выпускная) либо при старте BL-018 (продакшен-фронтенд после ДЗ-06) — что раньше

## Что обнаружено

- Топология N1 (асинхронный API + очередь + воркеры + k8s) живёт только в схеме L2 и таблице S00 —
  на самые дорогие решения проекта нет ADR.
- Нет ADR на local-first (D-020), который обесценил предпосылки ADR-007: экономика облака
  (кап 2 ₽, резерв 0,6 ₽) локально инертна, а в ADR-007 это не отражено.
- Нет решения о сосуществовании FSM с тул-контуром — его закрывает поправка ADR-002 в S31
  (актуализация S40: вопрос снят полностью — тул-контур удалён, BL-048/S39, D-041; остался
  только продуктовый вопрос топологии, см. ниже).
- `PRODUCT.md` называет HTTP API «не-целью», а L2 показывает его продуктовым контуром.

## Почему не в текущей вехе

Аудит отнёс E5 к выпускной. Пометки «цель / факт» в свёртках и схемах снимают остроту для V4 —
это S36; сами решения не влияют на артефакт ДЗ-05.

## Что делать

ADR-012 «Топология развёртывания» с честным вопросом из рекомендации №3 аудита: нужна ли очередь
при ≤ 10 пользователях. Отдельной записью — local-first (D-020) как ADR с пометкой неактуальных
предпосылок ADR-007 (R-C1, R-S4). Оба — решения куратора до правки ADR-007 и c4-l2.
