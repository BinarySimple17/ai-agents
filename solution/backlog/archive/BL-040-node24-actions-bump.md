# BL-040 — Node 24: actions/checkout@v4 и setup-python@v5 работают на принудительном Node 24 (deprecation Node 20)

- **Статус:** закрыт 2026-11-25 (S31, коммит 4c27e01): checkout v4→v7.0.1, setup-python v5→v7.1.0 — нативный Node 24
- **Дата:** 2026-11-25
- **Сессия-источник:** — (хотфикс D-035, живой прогон 45640357845 — предупреждение в логе)
- **Приоритет:** P3
- **Назначение:** S31, одним коммитом с BL-038/BL-035 (правка workflow без живого прогона не верифицируется)

## Что обнаружено

GitHub в логе прогона 45640357845 (2026-11-25) предупреждает: Node.js 20 deprecated,
«actions/checkout@v4, actions/setup-python@v5 forced to run on Node.js 24». Сейчас это
только предупреждение; когда таргет Node 20 у GitHub Actions уберут совсем, экшены на
старых мажорах начнут падать или молча менять поведение раннера.

## Почему вне скоупа сессии

Предупреждение не роняет прогон; бамп мажоров экшенов требует живого прогона для
верификации (урок setup-uv: web-чек ≠ тег существует — версии сверять `gh api` по
реальным тегам), и жечь отдельный прогон ради него не нужно.

## Что делать

Вместе с BL-038: бампнуть checkout/setup-python на актуальные мажоры под Node 24
(сверить существование тегов через `gh api`, желательно сразу SHA-пины по BL-038),
убедиться по логу, что предупреждение исчезло. Прогон совмещать с любой ближайшей
волной на milestone.
