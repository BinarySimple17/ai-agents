## Что обнаружено

S31 делает identity тул-контура обязательной (verified-токен для любого SQL-контура,
`--user` упразднён). Команда артефакта `hw-03/README.md:33` — `python -m apps.cli --user
u_logist "…"` — после S31 перестаёт работать на голове V4+ (нет флага `--user`; для
дефолтного контура требуется `--token`). Сверка с веткой сдачи ДЗ-03 выполнена при старте
S31 (требование куратора): в `milestone/v2` CLI имеет только `question/--quiet/--user/--plain` —
**флага `--token` там нет** (он появился в V4 с feat-005), поэтому вариант «добавить --token
в команды hw-03» повторил бы ошибку hw-02 («чужие поздние параметры, которых в ветке ДЗ
нет» — слова куратора). Команды hw-03 валидны для `milestone/v2` как есть; расхождение —
только с головой V4+.

## Почему вне скоупа сессии

D-037 (владелец, 2026-11-25): изменения — только в текущем ДЗ/вехе (hw-05/V4); правки
артефактов прошлых ДЗ — отдельными явными сессиями от ветки своей вехи. Суперседирует
внутри-сессийное разрешение «править только hw-03», выданное при старте S31.
