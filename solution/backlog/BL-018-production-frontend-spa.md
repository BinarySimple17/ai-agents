## Что обнаружено

Решение владельца (2026-11-22): после ДЗ-06 учебные вехи закрываются, и веб-интерфейс
переводится в продакшен — React/Vue SPA + FastAPI (фреймворк фронтенда — React или
Vue — зафиксировать при старте работ). До этого момента единственный веб-интерфейс —
Streamlit-демо (feat-022, D-032). Что влечёт прод-фронтенд:

1. **HTTP API становится контрактом**: D-005 («openapi не ведётся», интерфейсы —
   CLI/Streamlit) пересматривается — новая редакция ADR + контракт API (схемы
   запросов/ответов, версии, ошибки). Точка входа агента — оркестратор FSM, API —
   тонкая обёртка над composition (не новый слой бизнес-логики).
2. **Auth за пределами DevTokenAuth**: PRD §Auth — production = OIDC-адаптер
   (`AuthProvider` уже порт); сессии/токены для SPA, CORS, CSRF.
3. **Стриминг** — SSE или WebSocket (порт `StreamFinal` переиспользуется,
   `tool_calls`-расширение D-021 остаётся).
4. **Interactivity clarify**: interrupt/resume поверх HTTP — привязка к
   thread_id чекпоинтера (Valkey TTL 10 мин уже совместим), UI-состояние прогона.
5. **Observability**: хозяин `/metrics` переезжает со Streamlit-демо на прод-процесс
   (пересмотр решения ADR-010 v1.2 — долгоживущий процесс тот же принцип, другой носитель).
6. **Инфраструктура репо**: отдельный фронт-проект (Node-сборка) или `src/web/` +
   `src/apps/api.py`; политика веток/CI для артефактов сборки — решение при старте.

V4/V5; до старта D-005 действует без изменений.
