права-ограниченным пользователем уходит в **clarify-цикл**, а не degrade —

таблиц нет в мире агента, классификатор честно спрашивает «о каких сущностях
речь» → после капа раундов — clarification. Это канонное поведение (задокументировать
в README как честный исход deny-мира — валидно для hw-plan §5). Живой **degrade**
S15 показала на сцене «нет активного пути» (u_logist: customers×campaigns —

degrade с формулировкой «доступны данные по темам…». Для артефакта — взять
обе сцены (clarify-мир + no-path-degrade) или зафиксировать выбор в отчёте.
