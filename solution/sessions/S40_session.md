## Ловушки

1. **Реестр vs файлы:** `make archive` переносит файл закрытой записи при закрытии сессии, но
   строку реестра правит только ручная правка шапки записи — отставание строки = нормальный
   хвост, чинить правкой строки, НЕ перемещением файлов обратно.
2. **Планируемые сессии (⬜):** править только устаревший КОНТЕНТ (ссылки на удалённый контур),
   не статус шапки, не окна, не перечень задач без причины — это их сессии-исполнители.
3. **Канон не переписывать:** противоречие «журнал говорит заморожен — канон говорит удалён»
   чинится журналом; канон docs/ сверен волной S39 `aa9dabb`; исключение — S00 (в волну
   не входил): дрейф строк 53/85/118 (живые описания удалённого контура) — FIX-019 + BL-057,
   правка канона — вне скоупа этой сессии.
4. **Статусы шапки и гейты:** не забыть флип «◐ в работе» + старт-чекбокс до `make check`
   (гейт кусает стартуемую сессию), ARCH-GATE N/A — до первой правки журналов.
