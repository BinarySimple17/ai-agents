### Правила для исполнителя

1. Ветка `harness/roadmap-matrix` от `milestone/v4`; merge — в `milestone/v4` (D-031).
2. **Бэкап — отдельная orphan-ветка** `archive/specs-2026-11-24` (без истории основной ветки),
   только `.docs/` и `.drafts/`. D-011 не меняется: в основной истории их по-прежнему нет.
   Собирать в отдельном worktree, основное рабочее дерево не переключать.
3. **Push бэкап-ветки — действие наружу:** по явной команде куратора, после скана на секреты.
   Команды нет — ветка остаётся локальной, факт ждущего пуша — в `progress.md`.
4. **Матрица — новый трекаемый `docs/roadmap.md`.** Строки — элементы цели по архпакету v1.8+ (FR/NFR
   prd, решения ADR-001…011, целевой контур N1, экономика ADR-007, SAP ADR-011, eval); колонки —
   состояние (построен / в вехе Vn — сессия / в выпускной — BL / без владельца), источник, дата.
5. **Колонка «без владельца» — главная:** каждая такая строка получает решение куратора до закрытия
   сессии (веха, BL или «отказано»). Осталось без решения — строка помечается «ждёт решения» и
   попадает в `progress.md` → Blockers / Risks.
6. Матрица обновляется на закрытии каждой сессии: правило — в AGENTS.md (обязательный артефакт,
   End of Session). Механическую проверку (pre-flight `close-session`) здесь не добавлять —
   кандидат в S38.
7. Состояния — только из трекаемых источников: `feature_list.json`, `solution/sessions.md`,
   `solution/backlog/README.md`, код на HEAD.
