# Diagrams — диаграммы

Диаграммы хранятся **текстом (mermaid)** прямо в репозитории — ревьюятся в PR, как код, рендерятся на GitHub без внешних инструментов. Экспорт в картинки не ведётся (устаревает моментально).

Источник схем — архитектурный пакет v1.7 ([arch-package.md](../arch-package.md)); порядок чтения: C4 L1 → L2 → L3 → state → sequence → ER. Диаграммы провалидированы mmdc в пакете.

## Что здесь лежит

| Файл | Уровень | Что показывает | Когда обновлять |
|---|---|---|---|
| [c4-l1-context.md](c4-l1-context.md) | C4 L1 | Системный контекст: роли пользователей (RBAC), IdP, LLM-шлюз | Изменение внешних стыков |
| [c4-l2-container.md](c4-l2-container.md) | C4 L2 | Контейнеры + развёртывание: приложение (CLI + Streamlit-демо), Data Plane (PG, Valkey), Observability Plane (ADR-010), точки роста (SAP, ADR-011) | Изменение топологии/деплой-единиц |
| [c4-l3-agent.md](c4-l3-agent.md) | C4 L3 | Внутреннее устройство агента: узлы, рубежи, роутинг, лимиты, позиции кэша/декомпозиции | Изменение узлов/маршрута (с ADR-002/004) |
| [state-agent.md](state-agent.md) | FSM | Все исходы state machine: терминальные состояния, лимиты, `budget_stop`/`incomplete` | Изменение переходов (маршрут — только код) |
| [sequence-query.md](sequence-query.md) | Sequence | Тяжёлый запрос сквозь всю систему (alt-ветки: кэш, декомпозиция, retry) | Изменение сквозного сценария |
| [er-data-model.md](er-data-model.md) | ER | Каноническая модель данных: 7 бизнес-таблиц + настройки (`agent_*`) + `query_trace`, версии настроек (`settings_version`) | Любое изменение схемы — в том же PR, что и seed |

## Соглашения

1. Один файл — одна диаграмма; заголовок файла = тип диаграммы.
2. Изменение диаграммы, меняющее архитектурное решение, — сначала ADR (`docs/adr/`), потом диаграмма.
3. В каждой диаграмме — блок «Чтение схемы»/комментарии: решения, неочевидные из картинки, объясняются словами (инварианты, приоритеты, границы владения).
4. Модель данных ([er-data-model.md](er-data-model.md)) согласована с seed'ом и `agent_relationships` — расхождение считается багом документации (журнал: [solution/FIXES.md](../../solution/FIXES.md)).
5. Проверка mermaid перед коммитом: `npx --yes @mermaid-js/mermaid-cli` (mmdc) по файлу — в пакете диаграммы уже провалидированы; после правки — провалидировать заново.
